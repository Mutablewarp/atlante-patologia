# Missing assets

Images and diagrams a card or Pattern Page should have but cannot use yet, because no file with a verified
license exists (COMPLIANCE_PLAN §2, CONTENT_SCHEMA §5). The page shows a placeholder until the gap is closed.
Never add an image whose license, author or file page has not been checked.

## When to add an entry

- No acceptable photograph or micrograph was found (Wikimedia Commons file page, NCI Visuals PD, CDC PHIL PD).
- A candidate was found but its metadata is incomplete (creator unknown, license unclear, uploader ≠ author).
- A candidate is CC BY-SA and waits for owner approval (`ownerApproved: true`).
- An original SVG diagram is planned but not drawn yet.

## How to write an entry

One row per missing asset. "Candidate" is a file page URL, or `none found`. Close a row by linking the image id
of the YAML file in `src/content/images/` that now covers it.

| Date | Entity / pattern | Role | What it should show | Candidate | Blocker | Status |
|---|---|---|---|---|---|---|
| YYYY-MM-DD | `<entity-id>` | gross \| micro \| diagram \| imaging \| clinical | key finding to show | URL or `none found` | license \| author \| BY-SA approval \| not drawn | open \| closed: `<image-id>` |
