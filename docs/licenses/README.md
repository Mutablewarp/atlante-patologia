# Dependency license ledger

`dependencies.json` lists every npm package installed by `npm ci`: name, version, license, repository and whether it is a production or development dependency. It is generated by `npm run licenses` (`scripts/license-scan.mjs`, using `license-checker-rseidelsohn` 5.0.1). CI runs the same command and fails when a license is outside the allowlist and has no documented exception.

The file records the date and platform of the run. Optional native packages (`lightningcss-*`, `@img/sharp-*`) differ by operating system, so a run on Linux CI lists slightly different names than a run on macOS.

## Allowlist

MIT, ISC, BSD-2-Clause, BSD-3-Clause, Apache-2.0, 0BSD, CC0-1.0, BlueOak-1.0.0, OFL-1.1 for the self-hosted fonts, and Zlib (D050) for `pako`, which 3Dmol.js bundles (`(MIT AND Zlib)`). An SPDX `OR` expression passes when one option is on the list; an `AND` expression passes only when every part is.

## Documented exceptions

None of these packages reaches the published site. They run only during the build or the tests.

| Package | License | Why it is acceptable |
|---|---|---|
| `@axe-core/playwright`, `axe-core` | MPL-2.0 | Accessibility tests only; never bundled or published |
| `lightningcss`, `lightningcss-<platform>` | MPL-2.0 | CSS minifier run by Vite at build time; its code is not in the output |
| `caniuse-lite` | CC-BY-4.0 | Browser-support data read by browserslist at build time |
| `@img/sharp-libvips-<platform>` | LGPL-3.0-or-later | libvips binary that sharp loads during the build (unmodified, dynamically linked); not published |
| `@img/sharp-wasm32` | Apache-2.0 AND LGPL-3.0-or-later AND MIT | Optional WebAssembly build of the same; not published |
| `spdx-exceptions`, `spdx-ranges` | CC-BY-3.0 (with MIT) | SPDX data used by the license checker itself |

Add an exception only for a package that never ships to the browser, and always with a reason (in `EXCEPTIONS` in the script and in this table).

## Compatibility note

What the browser actually downloads is Preact (MIT), @preact/signals (MIT), ts-fsrs (MIT), idb (ISC), the Pagefind search runtime (MIT) and the Atkinson Hyperlegible Next and Fraunces fonts (OFL-1.1, credited with their license on the Credits page). Only when a learner presses “Load the 3D view” does the browser also download 3Dmol.js (BSD-3-Clause, with the GLmol, three.js and jQuery notices in its licence file) and the code it bundles: pako (MIT, with the zlib notice), iobuffer, netcdfjs and upng-js (MIT). Their full notices are reproduced on the Licences page, as BSD-3-Clause and MIT require. All are permissive and compatible with the project's MIT code license; the fonts keep their own OFL terms, which allow bundling with any software. Build-time tools (Astro, Vite, sharp, lightningcss) process the site but their code is not redistributed in `dist/`, so their licenses place no conditions on the published site. Site content is licensed separately under CC BY-SA 4.0 (see `LICENSE-CONTENT.md`).

This is an engineering summary, not legal advice.
